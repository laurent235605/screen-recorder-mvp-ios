# MARKETING_STRATEGY.md

Date: 2026-02-18
Scope: ScreenRecorderMVP growth + monetization

## 1) North Star
- Primary: Increase `purchase_success / paywall_shown`
- Secondary: Increase qualified top-of-funnel traffic to paywall

## 2) Target audience (initial)
- Short-video creators needing fast 9:16 export workflows
- Solo creators / indie operators with high publishing frequency

## 3) Channel priorities (first 30 days)
- Tier 1: 小红书, TikTok
- Tier 2: 抖音, X
- Tier 3: YouTube (long-form trust content)

## 4) Offer architecture
- App Pro subscription (core monetization): unlock TikTok 9:16 export
- External digital packs (optional): templates, SOP checklists, creator workflows

## 5) Content system (weekly cadence)
- 3x before/after clips
- 2x workflow tutorials
- 1x “mistake to avoid” educational post
- 1x product update/changelog post

## 6) Funnel design
1. Content post
2. CTA -> app install / landing page
3. In-app: onboarding -> paywall
4. Purchase / restore
5. Post-purchase usage + share prompt

## 7) KPI board (weekly)
- TOF
  - Content link CTR
  - Install intent proxy (landing clicks)
- MOF
  - `onboarding_completed / onboarding_shown`
  - `paywall_shown` count by `entry_point`
- BOF
  - `purchase_tapped / paywall_shown`
  - `purchase_success / paywall_shown`
- Quality
  - `export_success / export_started`

## 8) Experiment queue (marketing)
- E1: Hook style (pain-first vs result-first)
- E2: CTA copy ("Try free" vs "Export faster")
- E3: Entry-page structure (single CTA vs dual CTA)

## 9) 30-day action plan
- Week 1: Baseline content + KPI baseline snapshot
- Week 2: Launch hook A/B test
- Week 3: Adjust CTA and measure CVR delta
- Week 4: Keep winner + publish consolidated learnings

## 10) Risk controls
- Avoid over-reliance on one platform
- Keep one source of truth for KPI formulas
- Freeze event names to avoid tracking drift
